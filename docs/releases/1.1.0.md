# MeshArc 1.1.0

2026-09-23 · HarmonyOS NEXT · versionCode `100000003`

## 中文

这次更新重点改善 VPN 后台运行、连接状态显示与日常界面操作。

- **后台连接与流量通知**：连接后启动持续后台任务，通知中显示本次连接的真实上传、下载总量。
- **更稳妥的状态恢复**：短暂读取不到状态时保留已有后台保护；系统取消任务后延迟重试，用户主动关闭后尊重其选择。
- **连接反馈更准确**：心跳不再等待可选的设备探测完成；可选服务查询失败时避免误报 VPN 已断开。
- **长列表和手势修复**：修复首页设备列表无法滚动到底的问题，改善设备详情半模态的滚动及底部导航手势。
- **更新日志与导航**：修复更新日志关闭和显示偏好操作，优化底部导航图标、文字和渐变遮罩。

## English

This update focuses on VPN background operation, connection status and everyday UI interactions.

- **Background protection and traffic notification:** start a continuous task after connecting and show actual upload and download totals for the current connection.
- **More resilient recovery:** retain protection during brief status-read failures, back off retries after system cancellation, and respect explicit user dismissal.
- **More accurate connection feedback:** start heartbeats before optional peer probes and avoid false disconnect reports when optional service snapshots fail.
- **Long lists and gestures:** fix scrolling to the end of Home device lists and refine device-detail sheet scrolling and bottom-navigation gestures.
- **Release notes and navigation:** fix dismissal and display-preference actions and refine navigation icons, labels and gradient masking.

### Upgrading from the early GitHub release

The previous public GitHub package was `0.3.19-release`. Subsequent work also introduced MeshSend file transfer, Taildrive browsing, HosPlayer integration, app and folder locks, and adaptive phone, tablet and 2in1 layouts. See the in-app release history for details.

### Installation and compatibility

Prefer [Huawei AppGallery](https://appgallery.huawei.com/app/detail?id=io.github.tailscaleohos). The GitHub HAP uses the project's AppGallery Release signing material; device eligibility and sideloading restrictions depend on HarmonyOS and the profile type. It is not guaranteed to install directly on every device. Preserve existing app data; do not uninstall a working version merely to try sideloading.

Source compatibility baseline: HarmonyOS 6.1 / API 23, arm64. MagicDNS remains disabled; use Tailscale IP addresses. Open the app and reconnect manually after a device reboot.

### Validation scope

Passed 14 background-task lifecycle and race tests, the Release build, AArch64 Go/N-API artifact checks, and Huawei's application and profile signature verification. Package metadata confirms `debug=false` and the complete vendor `26.0.0.105 Release` SDK. The build script now recognizes the vendor HMS metadata filename, avoiding a fallback to an incomplete older SDK.

Earlier Debug-device evidence covered 12 minutes of continuous screen-off and subsequent network reachability while attached to USB and charging; it does not establish indefinite battery-only background operation. The maintainer opted to skip a full release review; physical-device regression was not repeated on this new Release HAP.
