## MeshArc 1.1.0

September 23, 2026 · Build `100000003` · HarmonyOS NEXT

This release improves background VPN operation, connection feedback and everyday navigation.

### Tailscale OHOS is now MeshArc

If you used an earlier release under the name **Tailscale OHOS**, welcome to **MeshArc**! The app now has its own name while continuing to bring Tailscale networking to HarmonyOS. The GitHub repository remains `flypigJ/Tailscale-OHOS`.

MeshArc is an independent community client and is not affiliated with or endorsed by Tailscale Inc.

## What's new

### Background connection and traffic updates

A continuous background task now supports the VPN while MeshArc is in the background. The connection notification shows actual upload and download totals for the current session.

Background protection now tolerates brief status-reading failures. Recovery retries are spaced out after system cancellation, and explicit user dismissal is respected.

### Clearer connection feedback

Connection updates no longer wait for optional device probes. Failed lookups for optional services no longer incorrectly report that the VPN has disconnected.

### Catching up from an earlier GitHub release

Since the previous public GitHub build, MeshArc has also gained:

- **MeshSend:** send and receive files through Taildrop.
- **Taildrive:** browse authorized remote shares and upload or download files.
- **HosPlayer integration:** discover Jellyfin, Emby and Plex servers and open them in your player.
- **App and folder locks:** use system authentication to protect local access.
- **Adaptive layouts:** a native interface for phones, tablets and 2in1 devices, with light and dark themes.

## Fixes and improvements

- Fixed long device lists that could not scroll all the way to the bottom.
- Improved scrolling in device-detail sheets and bottom-navigation gestures.
- Fixed closing the release-notes panel and changing its display preference.
- Refined navigation icons, labels and gradient overlays.
- Fixed build-script detection of the vendor SDK metadata to select the complete installed SDK.

## Get MeshArc

Visit [Huawei AppGallery](https://appgallery.huawei.com/app/detail?id=io.github.tailscaleohos) for the available store version, or read the [installation guide](https://github.com/flypigJ/Tailscale-OHOS/blob/main/docs/getting-started.md) for other installation options.

This build targets **HarmonyOS 6.1 / API 23, arm64**. MagicDNS remains disabled, so use Tailscale IP addresses. Reconnect manually after restarting your device.
